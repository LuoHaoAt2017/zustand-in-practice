# 《Zustand 状态管理：从能用到用好》

## 项目简介
这是一个专注于zustand状态管理的案例学习网站，由浅入深分为6大章节，采用微前端架构实现。

## 技术栈
- **前端框架**: React 19 + TypeScript
- **状态管理**: Zustand 4.5
- **微前端**: Qiankun 2.10
- **构建工具**: Vite 7
- **包管理**: PNPM
- **开发语言**: 中文注释

## 项目结构
```
zustand-in-practice/
├── src/                 # 主应用源码
├── apps/               # 6个子应用
│   ├── chapter-1/      # 第1章：为什么选择Zustand
│   ├── chapter-2/      # 第2章：基础用法 + 常见5个坑
│   ├── chapter-3/      # 第3章：模块化设计实践
│   ├── chapter-4/      # 第4章：复杂业务场景
│   ├── chapter-5/      # 第5章：性能优化实战
│   └── chapter-6/      # 第6章：实战重构
├── .claude/docs/       # 详细章节文档（共6章）
└── 配置文件等
```

## 快速开始

### 环境要求
- Node.js 18+
- PNPM 8+

### 安装依赖
```bash
# 安装根依赖和所有子应用依赖
pnpm install
```

### 开发模式
```bash
# 同时启动主应用和所有6个子应用
pnpm dev
```

访问 http://localhost:3000 查看主应用。

### 构建项目
```bash
# 构建所有应用
pnpm build:all
```

### 单独运行
```bash
# 只运行主应用
pnpm dev:main

# 运行特定章节
pnpm dev:chapter-1
pnpm dev:chapter-2
# ... 其他章节类似
```

## 微前端架构
- **主应用**: 提供导航框架，集成Qiankun
- **子应用**: 每个章节独立开发、构建、部署
- **开发体验**: 支持独立运行和集成运行
- **通信**: 通过Qiankun props和自定义事件通信

## 设计理念
1. **渐进式学习**: 从基础到高级，层层深入
2. **实战导向**: 每个章节都有完整可运行的案例
3. **最佳实践**: 遵循Zustand官方推荐模式
4. **性能优先**: 关注渲染优化和状态管理性能

## 贡献指南
1. 每个章节的详细文档在 `.claude/docs/` 目录
2. 子应用实现应遵循对应文档的设计
3. 所有注释使用中文
4. 遵循TypeScript严格模式
