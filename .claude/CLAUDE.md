### 项目概览
本项目是一个专注于zustand状态管理的案例学习网站.
由浅入深分为6大章节,具体信息参考 @docs

### 总体目标
整个项目要求使用微前端架构,微前端技术选型你自己确定.
根据 docs 文档中每一集的文档描述,实现案例.每一集的案例作为一个独立的子应用存在.

### 实现要求
首先,根据每一章的目标,设计并书写每一章的文档.
其次,根据每一章的文档,创建每一章对应的子应用,实现子应用的功能.
最后,创建一个主应用,支持在主应用中通过tab在各个子应用之间进行切换.

### 技术选型
微前端技术选择 qiankun
react + typescript + zustand
